# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/ofershap/dibbur/security/advisories/new). Do not put exploit details, tokens, signing material, recordings or private transcripts in a public issue.

Include the affected version/platform, a minimal reproduction and the security impact. Use synthetic recordings or invented transcript text if an example is needed. There is no guaranteed response time or bug bounty.

Transcription runs locally. Downloading models and updates uses the network. Optional AI cleanup can send transcript text to the provider the user selects; a local Ollama provider is a different route. A transcript archive stored in a synced folder follows that folder's sharing and sync settings.

Maintainer fixes target the current release; older releases may need an update. Self-signed Mac builds are not Apple-notarized builds. Report suspected release or updater tampering through the private channel above.
